# Hi, I'm Arlen

Customer support specialist moving toward technical investigation work: L2/L3 support, application support, and SQL/data-driven troubleshooting.

## About

I currently work as a Senior Customer Support Specialist at a B2B SaaS company building document scanning and PMS integrations for the hospitality industry. Before that I spent close to two decades running my own ventures, including building and operating a high-traffic e-commerce marketplace with hands-on API integration, database management, and web scraping work.

I'm not a software engineer and I don't want to be one. What I'm good at is taking a vague or broken customer report and turning it into a concrete, evidence-backed answer: what happened, why it happened, and what the data actually shows. This profile is where I practice and document that kind of investigative work.
